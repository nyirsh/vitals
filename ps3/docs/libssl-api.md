# Sony's PS3 libssl (cellSsl_Library 1.1, firmware 4.93): its exports

RSA SSL-C 2.7.0.3 (its X.509 part 2.1.1), SSL 3.0 and TLS 1.0 only. One library, `cellSsl`, with
114 functions: the public `cellSsl*` API games call, and the OpenSSL-style one Sony's libhttp
and NP modules call. Names from RPCS3's module table or found by hashing (tools/names); the
others are to be named from what their code does. "Address" is the function descriptor in
Sony's module; "Callers" are the modules of the 4.93 dumps that import it (games call the
public ones too).
